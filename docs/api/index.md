# API reference

Generated from the docstrings of the public modules; each page shows the names
in that module's `__all__`. Everything listed under `ggmanim` itself can be
imported from the top level (`from ggmanim import geom_point`); the
subpackages also export their classes and helpers (`ggmanim.geoms.Geom`,
`ggmanim.scales.ScaleContinuous`, ...).
