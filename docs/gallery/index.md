# Gallery

The rendered gallery is coming soon. Until then, every file in
[`examples/`](https://github.com/atzheng/ggmanim/tree/main/examples) is a
runnable scene; render the stills of one with

```bash
manim -ql -s -a examples/gallery.py
```

or of all of them with `scripts/render_examples.sh <media_dir>`.

- `examples/gallery.py`: scales, guides, themes and palettes, one scene per feature.
- `examples/gallery_geoms.py`: one scene per geom/stat/position idea.
- `examples/gallery_facets.py`: `facet_wrap` and `facet_grid`.
